# Security Policy

## Supported versions

Security fixes are currently applied to the latest release candidate and the active development branch. Older releases are not maintained independently.

## Reporting a vulnerability

Please do not disclose vulnerabilities, application tokens, private keys or publishing credentials in public issues.

Use the repository's [private vulnerability reporting page](https://github.com/Sekuramis/onyx4j/security/advisories/new) if available. Otherwise, contact the maintainer privately through an established contact channel.

Include the affected Onyx4J version, impact, minimal reproduction, relevant sanitized logs and suggested mitigations if available. Do not test against systems or applications without authorization.

The maintainer will review reports as availability permits and coordinate disclosure and fixes with the reporter.

## Scope

This policy covers the Onyx4J Java library and its official project infrastructure. Vulnerabilities in the underlying Onyx platform should be reported to its operators.
